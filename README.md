# Doces Yncantos App

Aplicativo Android do projeto "Monte seu Bolo", para montar pedidos de bolo. A API REST (Spring Boot) fica em [doces-yncantos-API](https://github.com/DuarteVn/doces-yncantos-API).

> Status: em desenvolvimento (estrutura inicial).

**Stack:** Java 17, Android SDK 34 (minSdk 24), Gradle.

## Executar

1. Abra esta pasta no Android Studio.
2. Aguarde o sync do Gradle (o `local.properties` é gerado automaticamente).
3. Rode em um emulador ou dispositivo.

Via linha de comando:

```bash
./gradlew assembleDebug      # Linux/macOS
gradlew.bat assembleDebug    # Windows
```
